帮助

1. 获取米游社 Cookie

电脑浏览器登录 https://www.miyoushe.com/ → 按 F12 打开开发者工具 → Network → 刷新页面 → 任意请求的 Request Headers 里复制完整的 Cookie 值（含 account_id/cookie_token 等字段）。粘贴到「用户管理 · 添加用户」。

Cookie 属于登录凭据，切勿发给他人；程序中只保存在你自己的 Cloudflare KV。

2. 签到结果含义

状态含义
success签到成功
already今天已经签过
skipped没有找到对应角色 / 未绑定该游戏
failed网络、接口变更、验证码或风控导致失败
cookie_expiredCookie 失效，需要重新复制

3. 常见问题

-10002 未查询到游戏角色：Cookie 不含账号会话字段、已不是最新会话，或该账号未在米游社绑定对应游戏。请在米游社网页重新登录后复制最新 Cookie。

出现验证码 / 风控：请停止自动任务，改用手动签到，不要尝试绕过。

Cookie 失效：删除旧 Cookie 重新获取。不要在聊天/Issue/第三方网站粘贴 Cookie。

4. 推送渠道

Server酱：填 SendKey；飞书：填机器人 Webhook，若开了签名再填密钥；钉钉：填 access_token 或完整 Webhook，开了关键词安全要填关键词，开了加签填密钥；Telegram：填 Bot Token 与 Chat ID（给 Bot 发一条消息后用 getUpdates 获取）；自定义 Webhook：填 URL，程序会 POST JSON（占位符 {title}、{message}、{event}、{time}）。

5. 定时说明

所有账号在同一天使用同一个随机时刻（基准时间 ± 抖动秒）批量执行；时间按「全局设置」里的时区计算。如当天已执行，不会重复执行。
